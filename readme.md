Funcionalidades do Sistema:
Para Alunos:
Página Inicial - Visão geral do sistema

Lista de Cursos - Visualização de todos os cursos disponíveis

Registro de Conta - Formulário para criar nova conta

Login - Acesso à área do aluno

Matrícula em Cursos - Matricular-se em qualquer curso (apenas uma vez por curso)

Dashboard do Aluno - Visualizar matrículas e status

Para Administradores:
Dashboard Admin - Estatísticas do sistema

Gerenciar Cursos - Adicionar, editar e excluir cursos

Gerenciar Alunos - Ver lista de alunos cadastrados

Gerenciar Matrículas - Aprovar ou rejeitar matrículas pendentes

Persistência de Dados:
Todos os dados são armazenados no localStorage do navegador

Os dados permanecem mesmo após fechar o navegador

Inclui dados de exemplo para demonstração

Como Usar:
Abra o arquivo HTML em qualquer navegador

Explore os cursos como visitante

Crie uma conta de aluno

Faça login e matricule-se em cursos

Acesse o painel administrativo para gerenciar o sistema

O sistema está completamente funcional sem necessidade de backend, usando apenas HTML, CSS e JavaScript puro.
